# 模型与数据

## 模型资产

BaseModel 包含公开数据训练的专家和自回归生成器。公开训练数据不含定量 MIC 标签，首次实验校准时初始化 MIC 预测头。FinalModel 使用经过偏好训练的 MIC 预测头，以及冻结的 ESM3、三个专家和 575 蛋白评分面板。

`configs/assets/downloads.json` 固定 Hugging Face 版本及文件校验值。模型下载并校验后保存在 `assets/`，可通过 `MDRAMP_ASSETS` 指定其他目录。下载中断后重跑原命令即可续传，需要代理时设置 `HTTPS_PROXY`。校验失败会明确报错；将损坏文件移走后重试，必要时还需清理对应的 Hugging Face 下载缓存。

自定义模型需提供 `scorer.json` 和有效的资产路径。校准保存独立的新模型，仅在指定 `--update-final` 时更新默认模型指针。

## 公开数据训练

`data/public/` 包含序列表、理化描述符、已记录的教师评分、配对筛选证据和训练计划。训练使用已记录的教师评分，不会重新运行教师模型生成评分。源码交付不包含大型 ESM3 特征缓存。

缺失特征自动计算到 `data/public/.feature_cache/`，支持中断后继续编码。输入和已有缓存均校验哈希；重建缓存绑定序列、模型权重与编码环境。重建特征与历史缓存可能存在微小数值差异，不承诺逐位一致的历史重训。CPU 全量编码和训练耗时较长。

## 校准与结果解释

校准将跨菌株观测聚合为每条多肽的最优 MIC 区间，菌株不是预测输入。`>128` 等右删失值保留边界。默认标签除数为 10，可用 `--mic-divisor` 调整。冲突的重复观测会报错。表格列名区分大小写，序列自动去空白并转大写。

FinalModel 使用调整后的标签和显式排名偏好训练。偏好在固定候选集合中拟合，排名取决于参与排序的集合，不能据此认定独立预测性能。Demo 序列参与过校准，观测归属保留在 `demo/provenance.json`，具体解释见 `demo/README.md`。

候选生成采用预训练自回归策略采样、理化过滤、通过 `--exclude` 提供的已测序列精确排除，并使用所选 MIC 模型重新排序。每次请求不会重新进行强化学习，也不构成实验安全性验证。

## 研究数据

完整实验记录及候选预测表随论文补充材料提供；仓库只保留选定的六条 Demo 序列。

## 复现

运行依赖固定于 `configs/requirements-runtime.lock.txt`，通过 `environment.yml` 安装。每次运行记录命令参数和资产哈希，不覆盖已有结果目录。

已在 macOS ARM64 验证 Demo 预测、小规模校准与生成、特征重建及单元测试。这些工程检查不等同于完整历史轮次复现或独立生物学验证。尚未独立验证 Linux 实机，原生 Windows 不支持，请使用 WSL2。

上游模型与数据的许可分别适用。Hugging Face 模型卡的许可说明不自动覆盖所有源数据或本源码仓库。

FinalModel 已加入阴性约束：27 条 R0–R2 实验阴性和 57 条公开训练阴性均预测 MIC＞256 μg/mL；其余 203 条原始序列最大变化约 1.05%，指定排名保持 1、5、8。公开留出样本仅 7/12 条超过 256。这些序列曾参与 AMP 预训练，部分原文证据仍待核验，因此属于内部 MIC 预测头留出评估，不是独立外部验证。
